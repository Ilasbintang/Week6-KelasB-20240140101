# Week 6 - Fetch API & Form DOM (Individu)

1. **index.html** - Fetch API ke https://dummyjson.com/products, menampilkan nama & harga produk, dengan loading dan error handling.
2. **form.html** - Form pendaftaran workshop dengan DOM, event listener (submit, input, change, reset), validasi, dan umpan balik dinamis.

## Struktur
```
css/  form.css  index.css
js/   form.js   index.js
form.html

```

Jalankan dengan membuka `index.html` di browser (disarankan memakai Live Server di VS Code).
